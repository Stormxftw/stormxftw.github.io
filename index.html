04 · story

  
From Code Louisville to local agents.

  
I started by building small tools and posting them online. Code Louisville taught me C#. I worked in .NET, then moved to TypeScript and Python. Agents changed how I work: now I write specs and corrections, and the agents write most of the code. A correction only needs to be made once — it is saved as a skill and applied from then on. This machine runs games at night and agent tasks during the day. One plugin produced fifty-seven worktrees. A backup job runs at 3:30 every morning. Everything is local and open source, so the tools can be inspected and run by anyone.
